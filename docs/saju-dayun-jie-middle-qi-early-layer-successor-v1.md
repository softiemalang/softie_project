# 起運 `節止·不論中氣` early textual-layer bounded successor v1

상태: `bounded chronology/textual-layer successor`, `五行精紀로의 직접 historical bridge 미확정`, `최초성·직접 계보·보편 규칙·readiness blocked`

기준일: `2026-08-25 KST`

이 문서는 [《五行精紀》 卷33의 `節·氣·中氣` 관찰 v2](./saju-wuxingjingji-vol33-jieqi-middleqi-observation-successor-v2.md)와 [명시적 direct-rule audit v1](./saju-dayun-jie-middle-qi-direct-rule-successor-v1.md)를 덮어쓰지 않는 additive successor다. 목표는 `止論節不論中氣·中氣不論` 계열 문장이 더 이른 명리 문헌의 실제 원면에서 어느 textual layer까지 직접 나타나는지 시대·서지 경계와 함께 좁히는 것이다. 검색 결과·OCR·텍스트 mirror는 page locator 또는 secondary corroboration으로만 사용하고, 실제 page image가 없는 문장은 primary witness로 승격하지 않는다.

## 1. Bounded conclusion

이번에 안전하게 닫히는 범위는 다음이다.

1. 직접 대조한 더 이른 계열의 page surface들, 특히 《珞琭子》·《五行精紀》·NLC 《淵海子平》·NLC 《神峰通考》·NLC 《三命通會》는 `節`/`節氣`/`節令`을 target으로 세거나 `三日為年`을 설명하지만, 이번에 확인한 page window에서 `止論節不論中氣` 또는 `皆遇節即止。中氣不論`을 직접 읽을 수 없었다.
2. Harvard 공식 IIIF 원면의 《三才發秘》 `起大運訣`에는 `其法止論節不論中氣`가 직접 보인다. Harvard catalog 표시는 `[China : s.n., 1697?]`이므로, 이는 **이 bounded corpus에서 확인된 가장 이른 명시 규칙의 catalog-dated surface**로만 기록한다. 최초 발생·최초 문헌·정확한 편찬연대를 주장하지 않는다.
3. 공개 NLC-attributed 《子平命術要訣》 p.18(인쇄면 `十四`)에는 `皆遇節即止。中氣不論`이 직접 보이며, 같은 면에 `交大雪節` worked example도 있다. 이 item은 metadata상 민국 16년[1927]으로 표시되므로 Harvard surface보다 후대의 직접 corroboration이다.
4. 따라서 초기 textual layer는 현재 다음 두 층으로만 좁혀진다.

   ```text
   older inspected layer  = future/past 節·節氣·節令 target + day/hour counting
   explicit later layer   = 止論節 / 遇節即止 + 不論中氣
   ```

5. 위 두 층 사이의 **문구 반복**은 직접 page-level textual corroboration이지만, 《五行精紀》가 후자의 명시 규칙을 수용했다는 copy-level bridge, 특정 공통 저본, 직접 계보, 판본 선후를 닫지 않는다. 《五行精紀》 卷33은 v2의 `節氣日`·`過去節`·`一辰十歲…三日為年` 경계를 그대로 유지한다.

## 3. 직접 page evidence

### 3.1 초기 textual layer: 《珞琭子》

기존 direct page audit의 source identity와 hash는 [textual-layer provenance successor](./saju-wuxingjingji-vol33-textual-layer-provenance-successor-v1.md)에 보존되어 있다. 이번 문서에서 그 evidence를 다음처럼 한정한다.

| surface | 직접 관찰 | 판정 |
| --- | --- | --- |
| NLC `121839` p.8–9 | `運行則一辰十歲折除乃三日為年`; `李仝曰` 아래 `一辰十歲·三日為一年·一日主四箇月` 계열 | 본문·왕씨 주석·李仝 gloss의 textual layer는 direct |
| NCL `06580` p.10 | 같은 `一辰十歲·三日為年·一日主四箇月` 계열의 문자면 | bounded corroboration; p.10만으로 발화 귀속·계보는 닫지 않음 |
| 두 surface의 inspected window | `止論節不論中氣`·`中氣不論` | 직접 관찰하지 않음 |

따라서 `一日主四箇月`을 `中氣不論`의 원형이나 같은 textual layer로 연결하지 않는다. 두 문구의 후대적 공존 여부와 《五行精紀》로의 전승은 별도 문제다.

### 3.2 《五行精紀》 卷33

v2에서 고정한 직접 관찰을 다시 요약한다.

```text
陽男陰女大運以生日後未來節氣日為數順而行之
陰男陽女大運以生日前過去節氣日為數逆而行之
運行則一辰十歲折除乃三日為年
```

NLC p.111의 `過去節`과 K3 인접 문맥의 `起運`·일반 `氣` 용례는 source-local lexical evidence다. 그러나 inspected windows에는 `節止`, `皆遇節即止`, `不論中氣`, `中氣不論`이 직접 나타나지 않았다. 이는 전 title·전 witness의 부재 증명이 아니다.

현재 판정:

```text
五行精紀 target/counting wording       = direct
explicit middle-qi exclusion           = not observed in inspected windows
adoption of 三才/子平 explicit wording = unresolved
五行精紀 ↔ explicit-rule title bridge  = unresolved
```

### 3.3 《淵海子平》와 《神峰通考》

NLC `99036` p.50의 `論起大運法`에는 다음 worked target이 직접 보인다.

```text
初一日立春後一日生男
順數至二月節驚蟄
```

같은 scan p.52의 별도 `論節候歌`에는 `正月立春雨水節 / 二月驚蟄及春分 / 三月清明并穀雨`가 보인다. 이 면은 seasonal inventory이지, 각 항목을 起運 target으로 선택하라는 exclusion rule page가 아니다.

NLC `511` 《神峰通考》 p.22에는:

```text
起大運法陽男陰女
... 折除三日為一歲
... 順數至二月節驚蟄
起大運法陰男陽女
... 逆數至初一日立春止
```

가 직접 보인다. 두 문헌 모두 `節`이 붙은 target과 day-counting을 보여주지만, 이번 원면에서 `中氣不論` 계열의 명시 배제 문장은 확인하지 않았다. 같은 worked example의 반복은 textual correspondence이지, 독립성·공통 저본·직접 계보의 증거가 아니다.

NLC `99036`의 public derivative는 [직접 PDF](https://upload.wikimedia.org/wikipedia/commons/1/11/NLC416-15jh007754-99036_%E6%B7%B5%E6%B5%B7%E5%AD%90%E5%B9%B3_%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE.pdf)이고, NLC `511` scan은 [Commons record](https://commons.wikimedia.org/wiki/File:NLC511-027032013020556-10361_%E7%A5%9E%E5%B3%B0%E9%80%9A%E8%80%83_%E7%AC%AC2%E5%8D%B7.pdf) 및 [직접 PDF](https://upload.wikimedia.org/wikipedia/commons/d/d1/NLC511-027032013020556-10361_%E7%A5%9E%E5%B3%B0%E9%80%9A%E8%80%83_%E7%AC%AC2%E5%8D%B7.pdf)로 재현한다. NDL의 [《明刊刻京臺增補淵海子平大全》 record](https://ndlsearch.ndl.go.jp/books/R100000002-I032158078)는 `宋徐升撰·明李欽編`이라는 catalog attribution을 제공하지만, 이 attribution을 현재 NLC scan의 물리적 제작연대·저본·계보로 확대하지 않는다.

### 3.4 《三命通會》

NLC derivative p.114–115를 다시 직접 확인해 다음만 보존한다.

```text
古人以大運則一辰十歲折除以三日為年
陽男陰女大運以生日後未來節日時為數順而行之
陰男陽女大運以生日前過去節日時為數逆而行之
... 二十九日申時立春 ... 折除過六十三時 ...
```

이 page window는 `節日時`·환산·`立春` worked example을 직접 보여주지만, `皆遇節即止` 또는 `中氣不論`을 직접 보여주지 않는다. 따라서 기존 검색/OCR·텍스트 mirror에서 보이는 더 긴 `中氣` 문장이나 `皆遇節即止`를 이 원면에 소급하지 않는다.

NDL 공식 catalog의 [《三命通會 12巻》 record](https://ndlsearch.ndl.go.jp/books/R100000136-I1970586434938919073)는 `(明)育吾山人著`와 `雍正13 [1735] 序`라는 catalog surface를 제공한다. 이 record는 작품 귀속·catalog witness의 bibliographic evidence일 뿐, 현재 `/private/tmp/saju-term-review/NLC416-94145-sanming-tonghui.pdf`의 exact item identity나 p.114–115 page provenance를 닫지 않는다.

### 3.5 명시적 exclusion layer: Harvard와 NLC

Harvard official IIIF surface:

- [IIIF manifest](https://nrs.harvard.edu/URN-3:FHCL:23921260:MANIFEST:3)
- [HOLLIS record](https://id.lib.harvard.edu/aleph/008088435/catalog)
- [direct canvas seq.547](https://nrs.lib.harvard.edu/URN-3:FHCL:23921260:MANIFEST:3/canvas/canvas-drs:52823058)
- [direct image DRS 52823058](https://mps.lib.harvard.edu/assets/images/drs:52823058/full/full/0/default.jpg)

공식 manifest metadata는 `陳雯. 三才發秘. [China : s.n., 1697?]`로 표시한다. seq.547 원면의 `起大運訣` 아래에 `其法止論節不論中氣`가 직접 보인다. `1697?`는 catalog estimate이므로 정확한 초출연대나 저술연대를 뜻하지 않는다.

NLC-attributed 《子平命術要訣》의 [Commons record](https://commons.wikimedia.org/wiki/File%3ANLC416-13jh000981-42624_%E5%AD%90%E5%B9%B3_%E5%91%BD%E8%A1%93%E8%A6%81%E8%A8%A3.pdf)와 [public PDF](https://upload.wikimedia.org/wikipedia/commons/c/c7/NLC416-13jh000981-42624_%E5%AD%90%E5%B9%B3_%E5%91%BD%E8%A1%93%E8%A6%81%E8%A8%A3.pdf)의 p.18(printed `十四`)에는:

```text
推大運時。先從所生之日起。陽男陰女順行。數至未來節。
陰男陽女逆行。數至已過去節。皆遇節即止。中氣不論。
```

같은 page의 worked example은 `十一月初二亥正一刻八分交大雪節`이다. Commons/NLC metadata의 `民國十六年[1927]`은 이 public derivative의 bibliographic date 경계로만 사용한다. NLC 기관 raw bytes·현재 page image의 machine binding·《五行精紀》와의 direct copy relation은 닫지 않는다.

## 4. Historical bridge 판정

| bridge | 판정 | 이유 |
| --- | --- | --- |
| older `節`/counting layer → Harvard `止論節不論中氣` | `bounded textual-layer corroboration` | 같은 起運 문제에서 direct page에 explicit exclusion이 나타나지만, 직접 인용·저본·전사 관계는 없음 |
| Harvard `止論節不論中氣` → 1927 `皆遇節即止。中氣不論` | `direct repeated wording, lineage unresolved` | 서로 다른 기관의 page image에서 문구 구조가 반복되지만, item 간 transmission record·rare variant·copy bridge 없음 |
| older `珞琭子` `一日主四箇月` → `中氣不論` | `unresolved` | 서로 다른 계산·selector 문구이며 같은 textual layer라는 direct page evidence 없음 |
| `三才發秘`/`子平命術要訣` explicit rule → 《五行精紀》 卷33 | `unresolved; not promoted` | 《五行精紀》 inspected windows에서 explicit exclusion 문장을 직접 확인하지 못함 |
| 어떤 문헌이 최초로 이 규칙을 만들었는가 | `blocked` | direct dated witness의 corpus가 불완전하고 catalog date가 composition date가 아님 |

이 표에서 `bounded textual-layer corroboration`은 source wording의 반복만을 뜻한다. `direct lineage`, `common ancestor`, `textual independence`, `정본성`, `semantic authority`로 읽지 않는다.
