# 子時 日界·`早子` exact-term bounded witness successor v2

상태: `早子 exact token observed`, `source-local day-wording direct`, `same-surface 四柱 co-location direct`, `normative 日柱·時柱 assignment unresolved`, `lineage·semantic authority·readiness blocked`

기준일: `2026-09-06 KST`

이 문서는 [기존 子時 direct-witness record](./saju-zi-day-boundary-direct-witness-successor-v1.md)를 덮어쓰지 않는 additive successor다. 이번 bounded question은 `早子`라는 정확한 인쇄 token이 기관 귀속/primary scan에 실제로 나타나고, 같은 physical page surface에서 四柱의 日干支·時干支 배속과 직접 결합되는지를 확인하는 것이다. `夜子`·`正子/子時正`의 기존 direct findings, 현대 23:00/00:00 정책, 용어 동치화는 이 문서에서 변경하지 않는다.

## 1. bounded conclusion

NLC 귀속 1938년 《千里命稿》의 PDF p.100(인쇄 p.97)에는 다음이 parent의 원면 재확인으로 직접 보인다.

```text
俗有所謂早子時夜子時之分別者。
乃以晚間十二時前為本日之夜子時。
十二時後為下日之早子時。
此論曆法則或可。論命則萬萬不可。
```

같은 page surface에는 黃君의 출생시각 `晚間十一時半`, `八字排列如上`, 그리고 parent가 원본 배열에서 읽은 `癸巳 甲寅 壬辰 庚子` 및 `壬日坐庫·時落庚子`가 함께 있다. 따라서 이 witness에서 다음 두 edge는 좁은 의미로 닫힌다.

```text
exact printed token `早子時`
  → source-local textual phrase `十二時後為下日之早子時`       = FACT / direct

exact token + birth-time example + displayed 四柱 on one page  = FACT / direct co-location
```

그러나 source는 곧바로 `論命則萬萬不可`라고 제한하고, p.101(인쇄 p.98)에서 다른 `辛卯日` 배열과 `夜子時` 해석을 논박 형식으로 병치한다. 원면에는 `早子時 → 이 日干支·이 時干支를 채택하라`는 독립적이고 무조건적인 명령문/화살표가 없다. 그러므로 다음은 여전히 닫히지 않는다.

```text
`早子`의 보편적 四柱 日柱·時柱 배속 규칙                      = UNKNOWN
이 source의 `早子` wording을 실제 displayed 八字에 적용한 인과 결합 = UNKNOWN
고전적 semantic authority·lineage·readiness                   = blocked
```

이번 결과는 `早子`를 `正子/子時正` 또는 `夜子`와 동치로 만들지 않는다. `早子`의 exact lexical existence는 더 이상 “not observed”가 아니지만, **normative Saju assignment는 여전히 UNKNOWN**이다.

## 3. FACT / INFERENCE / UNKNOWN 경계

### 3.1 FACT: exact token과 source-local wording

- p.100(인쇄 p.97)은 `早子時`를 실제로 인쇄한다.
- 같은 문단은 `十二時前為本日之夜子時`와 `十二時後為下日之早子時`를 나란히 둔다.
- 같은 문단은 `此論曆法則或可。論命則萬萬不可`라고 말한다. 이 제한 문구는 `早子`를 四柱 계산의 승인된 보편 rule로 읽지 못하게 하는 원면 사실이다.

### 3.2 FACT: same-surface Four-Pillar co-location

- 같은 p.100 surface에서 `黃君生於光緒十九年正月初七日晚間十一時半` 및 `八字排列如上`이 확인된다.
- 그 배열은 원면에서 `癸巳 甲寅 壬辰 庚子`로 보이며, 이어지는 문장은 `壬日坐庫。時落庚子`라고 적는다.
- 이는 exact token, 출생시각, 四柱의 日·時 field가 한 page에 물리적으로 공존한다는 직접 관찰이다. 그러나 source가 `早子時`를 그 배열에 적용한 것인지, 반대로 `早子`식 계산을 비판하기 위한 반례인지에 대한 명시적 문법 결합은 없다.

### 3.3 INFERENCE: 이번 frontier에서 좁혀진 부분

이 한 NLC page surface는 `早子`가 후대 현대 설명에서 만들어진 token이라는 가설을 배제하고, 적어도 1938년 scan의 해당 source surface에 exact printed terminology가 존재했음을 보여준다. 동시에 그 source 자체가 calendar wording과 命論 적용을 분리하고 반론 배열을 병치하므로, 이것만으로 `早子`의 normative 日柱·時柱 policy를 정할 수 없다는 것이 안전한 inference다.

### 3.4 UNKNOWN / conflict boundary

- `早子` exact token의 존재는 FACT로 승격한다.
- `十二時後 → 下日之早子時`라는 source-local textual relation은 FACT로 승격한다.
- `早子 → 특정 日干支·時干支`의 무조건적 Saju assignment는 UNKNOWN이다.
- p.100–101의 논박·대안 배열은 witness-internal argumentative tension이지만, 독립 witness 간 exact-token `CONFLICT`로 승격하지 않는다.
- `早子 = 正子/子時正`, `早子 = 夜子`, 현대 23:00/00:00, timezone, 진태양시, API 정책은 모두 이 evidence에서 결정하지 않는다.
