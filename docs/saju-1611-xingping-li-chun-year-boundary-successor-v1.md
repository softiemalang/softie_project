# 1611 《新刻星平總會命海全編》 正月初一日·立春日時 年界 successor v1

상태: `bounded additive frontier advance`; `1611 direct 立春為歲首 surface`; `birth-date→年干支 switch partial/unresolved`; `lineage·semantic authority·readiness blocked`

기준일: `2026-08-27 KST`

이 문서는 기존 [1915년 年柱–立春 operational rule frontier](./saju-year-pillar-li-chun-boundary-frontier-successor-v1.md)를 하향하거나 덮어쓰지 않는다. 이번에 새로 직접 확인된 것은 1611년본의 `逐年立春為歲首`라는 **연간 계산·명리 운용 표면**이다. 1915년 문서가 직접 닫은 출생 전후의 세 가지 年干枝 배정 규칙은 더 강한 exact birth-assignment evidence로 그대로 보존한다.

## 1. Bounded conclusion

현재 조사·직접 관찰 corpus에서 다음은 1611년 primary page image로 닫힌다.

```text
正月初一日 = 연간 가결·월력 계산의 기준일로 함께 사용
立春日時   = 交春의 일·시를 계산하는 절기 기준점
逐年立春為歲首 = 立春을 source-local 歲首로 명시
```

그러나 1611년본에는 다음을 한 번에 출력하는 출생 명례가 현재 확인되지 않았다.

```text
출생일시가 正月初一日과 立春日時 사이에 있음
    → 어느 年干支를 年柱에 배정
```

따라서 1611년 witness는 `立春年界`의 직접 연대 frontier를 1915년보다 이르게 하지만, 1915년의 `正月立春前/後·十二月立春後`와 같은 완결된 birth-date→年干枝 변환 frontier를 대체하지 않는다.

## 3. 두 기준점의 기능 분리

### 3.1 `正月初一日`

원면은 연간 가결을 `正月初一日`과 연결하고, 이어 월의 대소·윤월을 판별하는 절차를 둔다. 따라서 이 표현은 현재 다음과 같이 판정한다.

```text
정월 초하루
  → 연간 가결의 날짜 anchor
  → 음력 연월일 배열·월대소·윤월 계산의 입력
```

이 책의 해당 문장은 `正月初一日`을 이 문맥에서 곧바로 四柱 年柱의 교체점 또는 `歲首`라고 부르지 않는다. 또한 원면 표기는 `正月初一日`이지, 이 문서가 천문학적 `朔`과 동일하다고 명시한 것은 아니다. 그러므로 `正月初一日 = 朔 = 年柱 전환점`으로 확장하지 않는다.

### 3.2 `立春日時`

같은 연간 계산부는 `交春`을 일·시 단위로 산출하고, 뒤에서 `逐年立春為歲首`라고 명시한다. 따라서 이 표현은 다음의 source-local 기능을 직접 갖는다.

```text
立春日時
  → 交春의 절기 시각
  → 연간 掌中起命訣의 기준점
  → 명시된 source-local 歲首
```

이것은 1611년본의 direct `立春年界` surface다. 다만 이 문장만으로 후대 문헌의 현대식 `<`·`<=`, timezone, 천문 API endpoint를 복원하지 않는다.

### 3.3 둘의 관계

두 표현은 같은 연간 계산 안에 함께 있지만, 같은 종류의 경계로 취급되지 않는다.

```text
正月初一日 = 월력·연간 날짜 배열의 기준일
立春日時   = 태양 절기와 交春 시각의 기준점
立春       = 그 source-local 문맥에서 명시된 歲首
```

본문은 교춘이 십이월에 놓이는 경우도 연간 가결로 다룬다. 이는 두 기준일이 실제로 어긋날 수 있다는 직접적인 내부 신호다. 다만 그 어긋난 구간에 태어난 사람의 年柱를 실제로 어느 간지로 출력하는지는 이 witness의 확인 면에서 닫히지 않았다.

## 4. 실제 年干支 산출·명례의 범위

### 4.1 직접 닫힌 연간 계산

嘉靖四十三年 사례는 `甲子年正月初一日`과 `戊子日丙辰時立春`을 함께 산출한다. 이는 다음을 보여준다.

- 연도 간지를 연간 표의 항목으로 사용한다.
- 정월 초하루와 입춘의 일·시는 각각 계산된다.
- 입춘은 연간 계산에서 단순한 월명보다 강한 기준점으로 표시된다.

그러나 이 사례는 사람의 출생 명례가 아니라 연간 절기·역법 계산 사례다. `甲子年`이 입춘 전후 출생자에게 어떻게 배정되었는지를 출력하지 않는다.

### 4.2 동일 책의 `起八字例`

卷五는 이미 연도 간지가 주어졌을 때 `年上起月`로 月干을 시작하고, `甲己年` 사례에서 정월·이월의 月建을 전개한다. 또 `日上起時`에서는 이미 주어진 日干에서 子時의 時干을 시작하여 丑時 등으로 순행한다.

`甲子陽年二月初五日生` 사례는 `二月上建丁卯`와 大運 진행을 보여주지만, `甲子`를 정월 초하루와 입춘 중 어느 기준으로 골랐는지는 제시하지 않는다. 따라서 이 사례는 月柱·大運의 integrated example이지, 출생 年柱의 입춘 전후 switch example이 아니다.
