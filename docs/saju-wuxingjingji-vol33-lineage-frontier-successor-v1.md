### 3.2 `乙亥字` label과 현존본 연대

- NLC와 연세대의 현재 catalog는 각각 `乙亥字本` 또는 `金屬活字本(乙亥字)`를 표시하지만, 두 target copy의 현존 연도를 직접 제시하지 않는다. 두 record 모두 발행지·발행자·발행년을 미상으로 둔다.
- [AKS 「을해자」 해설](https://dh.aks.ac.kr/sillokwiki/index.php/%EC%9D%84%ED%95%B4%EC%9E%90%28%E4%B9%99%E4%BA%A5%E5%AD%97%29)은 1455년 주조와 관련된 기록을 소개하면서도 정확한 주조 시기·완료 시기는 확정되지 않았고, 약 150년 사용과 후대 보자/수리를 설명한다. 따라서 `乙亥字`라는 type-family label을 각 surviving copy의 제작일·판본 선후로 변환하지 않는다.
- 별도의 고려대 乙亥字 record는 `明宗年間`을 표시하면서도 9行17字·四周單邊·黑口·內向黑魚尾를 기술한다. 이 control은 같은 乙亥字 label이 특정 한 해 또는 한 printing state를 뜻하지 않을 수 있음을 보일 뿐, NLC·연세대의 계보를 증명하지 않는다. [고려대 dCollection control record](https://dcollection.korea.ac.kr/srch/popup/srchMetaViewPopup/000000134151)
- K3 공식 record는 `刊寫年未詳`이며, 해제의 1196년 周必大 서문·1228년 岳珂 서문과 岳珂 판본을 모본으로 했다는 설명을 보존한다. 이는 source/preface history와 기관 해제의 서술이지, 현재 K3 copy의 제작일·NLC/연세대와의 전승 방향을 직접 닫는 colophon은 아니다.

따라서 현재 연대 판정은 다음과 같다.

```text
乙亥字 type-family historical association       = secondary historical context
NLC current-copy date                            = unresolved
Yonsei current-copy date                         = unresolved
K3 current-copy date                              = unresolved
K3/NLC/Yonsei chronological order                 = unresolved
```

### 6.1 독립성의 분리 판정

```text
physical catalog-item separation       = bounded satisfied
same physical object                    = not established / effectively not claimed
digital-derivation independence         = unresolved
textual independence                    = unresolved
semantic independence/authority         = not established
```

세 기관이 서로 다른 item record를 갖는다는 사실은 같은 물리 책을 주장하지 않게 해 주지만, 각 책이 서로 독립적으로 전승된 텍스트 witness라는 결론은 주지 않는다. 특히 동일 본문이 공통 조상·직접 전사·후대 재각 중 어느 경로로 생겼는지 현재 evidence만으로 판별할 수 없다.
