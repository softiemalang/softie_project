# 1578–1697? 起運 `節`/`氣` explicit-rule family 1600 bounded successor v1

상태: `bounded pre-1697 direct-page successor`, `넓은 節/氣 대조 규칙 frontier advanced to 1600`, `정확한 不論中氣 frontier remains Harvard [1697?]`, `firstness·lineage·semantic authority·readiness blocked`

기준일: `2026-08-25 KST`

이 문서는 [1697년경 이전 起運 `節` selector·`中氣` 경계 successor](./saju-dayun-jie-middle-qi-pre1697-earliest-confirmed-successor-v1.md)를 덮어쓰지 않는 additive successor다. 목표는 1578년 《三命通會》와 Harvard catalog가 `[1697?]`로 표시하는 《三才發秘》 사이에서, `止論節·不論中氣·以節為限·遇節而止` 계열의 explicit rule이 실제 page image에 더 이르게 나타나는지 확인하는 것이다. OCR·검색 결과·후대 전사는 locator와 discovery로만 사용하고, 직접 본 page surface와 catalog/scan metadata를 분리한다.

## 1. Bounded outcome

이번에 실제 원면에서 확인된 새 earlier surface는 1600년으로 metadata가 붙은 NCL-attributed scan의 다음 literal이다.

```text
○論起大運法
...
其法論節不論氣
```

이것은 `節`과 `氣`를 대조하면서 起大運 법을 명시하는 **넓은 explicit-family direct surface**다. 그러나 `氣`와 `中氣`는 원문상 다른 literal이므로, 이 page를 `其法止論節不論中氣`의 동일 문구나 현대의 “中氣 배제” 규칙으로 교정·확장하지 않는다.

현재 두 frontier를 분리한다.

```text
넓은 `論節不論氣` 계열 explicit 節/氣 contrast = NCL-attributed scan, metadata 1600, PDF p.4
정확한 `止論節不論中氣` literal          = Harvard 《三才發秘》, catalog [1697?], seq.547
정확한 `皆遇節即止。中氣不論` literal    = 후대 NLC-attributed 《子平命術要訣》, metadata [1927]
```

따라서 기존의 정확한 `不論中氣` earliest-confirmed bound는 갱신하지 않고, 더 넓은 `節`/`氣` explicit-family bound만 1600으로 앞당긴다. 이는 1697?보다 이른 page-level explicit surface이며, 1578–1697? 구간에서 확인된 1600년의 새 direct surface다. 1578년 page window의 `節氣`·순역·환산과 1600년의 `論節不論氣`는 직접 대조 가능한 source wording이지만, 단계적 발전·직접 계보·공통 저본으로 읽지 않는다.

## 3. 1600년 page-level direct observation

PDF p.4의 `論起大運法` 문맥에서 세로 column을 실제 image로 확인했다. 판독을 안정적으로 닫을 수 있는 최소 literal은 다음과 같다.

```text
○論起大運法
其法論節不論氣
```

같은 page surface에는 `陽男陰女順`, `三日為一歲`, 미래로 수를 세는 문맥이 보인다. 이 문서에서 그것을 장문의 완전 전사·현대식 계산식·printed folio로 보충하지 않는다. 특히 다음은 **직접 확인된 literal이 아니다**.

```text
其法止論節不論中氣
皆遇節即止。中氣不論
以節為限
遇節而止
```

따라서 1600년 page의 판정은 다음처럼 고정한다.

```text
`○論起大運法`             = direct page observation
`其法論節不論氣`           = direct page observation
`論節不論中氣`             = exact literal not observed on this page
`不論氣` = `不論中氣`      = not promoted; lexical distinction preserved
```

## 4. 1578–1697? inspected interval

현재 실제 page를 확인한 dated/dated-by-catalog surfaces의 범위는 다음과 같다.

| 상대 위치 | 직접 관찰 | 이번 frontier에서 허용하는 말 |
| --- | --- | --- |
| 1578 NCL 《三命通會》 | `論大運`, `折除以三日為年`, future/past `節氣`, 순·역행 | 節氣 target·환산 layer의 direct baseline; explicit exclusion은 p.150–151에서 미확인 |
| 1600 NCL-attributed 《淵海子平》 계열 | `○論起大運法`, `其法論節不論氣` | inspected corpus에서 더 이른 **넓은 節/氣 explicit contrast** direct surface |
| 1611 Harvard 《新刻星平總會命海全編》 | `運論節候`, `順未來`, `逆尋過去` | 節候·future/past selector의 direct comparator; exact exclusion 없음 |
| 1647 東北大学 《命理正宗大全》 | official dated record only, no image | catalog candidate; 아무 rule literal도 승격하지 않음 |
| 1697? Harvard 《三才發秘》 | `其法止論節不論中氣` | checked corpus에서 exact `不論中氣` direct surface의 earliest-confirmed catalog-dated bound |

추가로 확인한 무연대 CADAL/Commons scan은 실제 page image를 제공하지만, 이 구간에 놓을 수 있는 독립적인 제작연대가 없어 chronology frontier에 편입하지 않았다. 해당 scan에서 본 page는 이 audit의 1600 direct date를 보강하지 않는다.

“더 이른”의 의미를 두 가지로 분리한다.

1. **정확한 literal 기준**: 현재 확인한 1578–1697? page들에서 `止論節不論中氣`의 1600년 이전 direct occurrence는 확인하지 못했다. exact literal frontier는 Harvard `[1697?]`로 유지한다.
2. **explicit-family 기준**: 1600 page의 `論節不論氣`는 1578의 단순 `節氣`보다 더 명시적인 節/氣 contrast이므로, broad family frontier를 1600으로 갱신한다.

이 둘을 합쳐 “1600년에 이미 `中氣` 배제 규칙이 있었다”고 말하지 않는다.

## 6. Reproducibility and preservation

이번 시각 검토는 공개 Commons page preview의 PDF p.4를 사용했다. repository에는 source PDF·page image·OCR을 추가하지 않았다. 165.12 MB 원 PDF와 기존 `/private/tmp` evidence는 건드리지 않았다.

재현 경로:

```text

direct digital locator: PDF p.4
direct literal: `○論起大運法` → `其法論節不論氣`
```

위 URL의 파일명은 실제 Commons 표기에서 `刻京臺`를 사용한다. 위 code block의 URL은 링크 재현성을 위해 URL encoding된 제목을 넣은 것이며, page locator는 PDF digital page이지 printed folio/page가 아니다.

이번 successor에 포함할 변경은 이 audit 문서 하나뿐이다. 기존 tracked 수정, 기존 미추적 Saju 연구 문서, 대용량 원본, 판단 불가 item은 stage·삭제·수정하지 않는다.
