# 1697년경 이전 起運 `節` selector·`中氣` 경계 earliest-confirmed successor v1

상태: `bounded pre-1697 direct-page successor`, `dated selector/counting frontier advanced to 1578`, `explicit 中氣-exclusion frontier unchanged at Harvard catalog surface [1697?]`, `firstness·lineage·semantic authority·readiness blocked`

기준일: `2026-08-25 KST`

이 문서는 기존 [起運 `節止·不論中氣` early textual-layer successor](./saju-dayun-jie-middle-qi-early-layer-successor-v1.md)와 [direct-rule successor](./saju-dayun-jie-middle-qi-direct-rule-successor-v1.md)를 덮어쓰지 않는 additive successor다. 목표는 1697년경으로 catalog 표시된 《三才發秘》보다 이른 **기관 record와 연결된 page image**에서 `論節不論中氣`·`以節為限`·`遇節而止`와 동의의 selector가 어느 수준까지 직접 나타나는지 좁히는 것이다. 검색 결과·OCR·전사·문헌 제목의 연대 귀속은 원면과 분리하며, 직접 읽은 범위 밖으로 문장을 보충하지 않는다.

## 1. Bounded conclusion

이번에 실제 원면에서 닫히는 결론은 두 frontier로 나뉜다.

1. 국립중앙도서관 공식 record가 `明萬曆戊寅(六年, 1578)刊本`으로 식별하는 《三命通會十二卷》의 공개 scan에서, 卷二의 `論大運` page surface를 직접 확인했다. 디지털 PDF p.150–151에는 `折除以三日為年者何`, `陽男陰女大運以生日後未來節氣...順而行之`, `陰男陽女大運以生日前過去節氣...逆而行之` 및 worked example이 보인다. 따라서 **연대가 catalog으로 붙은 selector/counting direct witness의 현재 examined-corpus bound가 1578년까지 앞당겨진다.**
2. 그러나 같은 p.150–151의 inspected window에서는 `論節不論中氣`·`以節為限`·`遇節而止`·`中氣不論`이라는 명시 문장을 직접 읽지 못했다. 이는 《三命通會》 전권의 부재나 1578년 copy 전체의 부재를 뜻하지 않고, 해당 page window에서 explicit exclusion을 승격하지 않는다는 bounded negative observation이다.
3. 1611년 Harvard scan의 《新刻星平總會命海全編》 卷五 page에는 `運論節候`·`順未來`·`逆尋過去`가 직접 보인다. 이 surface는 1578년 `節氣`·순역·환산층에 대한 별도 문헌의 page-level corroboration이지만, textual independence를 뜻하지 않으며 역시 `不論中氣`의 명시 문장으로 승격하지 않는다.
4. 명시적인 `節` 대 `中氣` 배제의 earliest-confirmed frontier는 여전히 Harvard official manifest가 `[China : s.n., 1697?]`로 표시하는 《三才發秘》 surface의 `其法止論節不論中氣`다. `1697?`는 catalog estimate이므로 정확한 초출연대·최초 발생을 뜻하지 않는다.

따라서 현재 frontier는 다음처럼 기록한다.

```text
dated direct selector/counting witness in checked corpus = NLC 三命通會, catalog 1578, PDF p.150–151
older direct `節氣`/future-past/day-counting layer       = confirmed, source-local
explicit `節不論中氣` direct witness                      = Harvard 三才發秘, catalog [1697?]
pre-1697 explicit exclusion in the inspected windows      = not confirmed
global first occurrence / direct genealogy                 = blocked
```

## 3. 1578년 NLC 《三命通會》 direct page observation

### 3.1 Record identity와 page scope

NCL 공식 record는 다음 bibliographic surface를 제공한다.

```text
正題名       三命通會十二卷
作者         (明)萬民英(撰)
版本         明萬曆戊寅(六年, 1578)刊本
裝訂         線裝; 12冊
書號/索書號  06589 / 306.5 06589
登錄號       rarecatx0136467
現藏者       國家圖書館
```

공개 scan PDF는 1000쪽이며, 卷二의 `論大運` surface가 digital p.150–151에 있다. p.150–151은 PDF digital locator이지 printed folio/page number가 아니다. 원면에서 printed locator가 식별되지 않아 이를 보충하거나 추정하지 않는다.

### 3.2 p.150–151에서 직접 읽은 범위

고해상도 page image를 기준으로 안전하게 전사할 수 있는 핵심은 다음이다.

```text
論大運
...
折除以三日為年者何
...
陽男陰女大運以生日後未來節氣 ... 順而行之
陰男陽女大運以生日前過去節氣 ... 逆而行之
```

같은 인접 page에는 `日時為數逆而行之` 및 날짜·시각·`立春`을 사용하는 worked example이 이어진다. 이 문서에서는 흐릿한 연결 문장이나 숫자를 임의로 복원하지 않고, 위와 같이 page image에서 식별되는 selector/counting 구조만 사용한다.

판정:

```text
`論大運` heading                         = direct page observation
future/past `節氣` selector               = direct page observation
陽男陰女 / 陰男陽女 순·역행              = direct page observation
`折除以三日為年` counting layer          = direct page observation
`論節不論中氣`·`以節為限`·`遇節而止`     = not observed in p.150–151
```

`生日後未來節氣`·`生日前過去節氣`는 source가 `節氣`라고 쓴 직접 문구다. 이를 곧바로 현대의 12節 enum이나 `中氣` 배제로 번역하지 않는다. 또한 p.150–151에서 literal이 보이지 않았다는 사실을 《三命通會》 전체나 해당 item 전체의 부재로 일반화하지 않는다.

## 4. 1611년 Harvard 《新刻星平總會命海全編》 comparator

Harvard Commons/IIIF의 1611년 v.4 卷五 scan p.3에서 다음이 직접 보인다.

```text
運論節候
順未來
逆尋過去
```

같은 surface에는 `方折除`와 순·역행 worked example의 문맥도 보인다. 이 문헌은 1578년 NLC page와 마찬가지로 `節`/`節候`를 기준으로 future/past 방향과 환산을 설명하는 pre-1697 direct comparator다. 그러나 해당 inspected page에서 `不論中氣` 계열 문구를 직접 확인하지 않았으므로 explicit exclusion witness로는 세지 않는다.

이 비교는 서로 다른 기관·파일에서 비슷한 selector wording을 읽었다는 뜻만 가진다.

```text
1578 NLC page  ↔ 1611 Harvard page = bounded textual correspondence/corroboration
1578 NLC page  ↔ 1611 Harvard page = not proof of common ancestor or direct copying
```

## 5. Explicit exclusion frontier: Harvard 《三才發秘》

Harvard official manifest metadata는 item을 `陳雯. 三才發秘 :. [China : s.n., 1697?]`로 표시한다. `seq.547` canvas의 `起大運訣` 아래에서 다음 literal을 직접 읽었다.

```text
其法止論節不論中氣
```

이 surface는 현재 checked corpus에서 explicit `節`/`中氣` exclusion을 직접 닫는 bound다. 다만 다음을 모두 별도로 unresolved로 둔다.

- `1697?`를 정확한 제작·편찬·초출 연도로 확정하지 않음.
- 이 문장이 그 이전 문헌에서 이미 존재하지 않았다고 주장하지 않음.
- 1578년 《三命通會》 p.150–151에 이 문장이 없다고 전권 부재로 확대하지 않음.
- 《三才發秘》와 《五行精紀》 사이의 copy-level binding·직접 인용·공통 저본을 설정하지 않음.
