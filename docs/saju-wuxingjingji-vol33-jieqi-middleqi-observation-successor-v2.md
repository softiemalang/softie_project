## 2. 새로 직접 확인된 표현

### 2.1 `氣`의 두 층위

장서각 p.73–83에는 `氣`가 실제로 반복되지만, 확인된 용례는 起運 target을 고르는 문장이 아니라 오행·운세 상태를 설명하는 문맥이다. 예컨대 다음과 같은 짧은 문자열이 보인다.

- p.73: `天氣`가 `行運至五行休敗之地`와 이어지는 문맥
- p.80: `有氣象`이 명식·생시의 상태를 설명하는 문맥

이 관찰은 卷33 내부의 `氣`가 모두 `節氣` 또는 `中氣`를 뜻하지 않는다는 source-local 구분을 가능하게 한다. 반대로 起運 target 문장에서는 v1에서 확인한 `未來節氣日`·`過去節氣日`이 직접 쓰인다. 두 층위를 하나의 현대 용어 또는 하나의 selector로 합치지 않는다.

### 2.2 인접 문맥의 `起運`

장서각 p.73의 대운 설명에는 `起運`이라는 문자가 직접 보이며, 앞뒤는 `行運`을 약법·연령·월수와 연결하는 서술이다. 이로써 해당 페이지가 起運 관련 인접 문맥임은 확인되지만, 그 문맥만으로 `節` 선택의 독립 규칙이나 `中氣` 배제 규칙을 복원하지 않는다.

### 2.3 `節`과 `節氣`의 경계

NLC p.106–110에서는 `立春` 사례 뒤의 대운 설명이 계속되고, p.111에서는 `過去節`이라는 결합이 직접 보인다. 기존 v1의 p.104–105 `過去節氣日`과 나란히 놓으면, 이 witness에는 다음 두 표기가 모두 관찰된다.

- `節氣日`: 起運 target을 지시하는 문장 안의 표현
- `過去節`: 뒤이은 문맥의 짧은 표현

그러나 p.106–111과 K3 p.73–83을 추가로 확인해도 `過去節`을 “遇節即止”의 절차어로 정의하거나 `中氣`와 대비하는 문장은 직접 나타나지 않았다.

## 4. 이 witness 안에서 확정 가능한 규칙 범위

현재 직접 근거로 닫을 수 있는 범위는 다음과 같다.

1. 卷33 「大運」의 방향 문장은 양남·음녀와 음남·양녀를 나누고, 각각 `生日後未來節氣日`·`生日前過去節氣日`을 세는 대상으로 제시한다.
2. 확인된 worked example은 `立春`과 경과 `時`를 사용한다.
3. 卷33의 앞부분에는 `運行則一辰十歲折除乃三日為年`이 직접 보인다.
4. 같은 卷33 인접 문맥에는 `過去節`과 일반적인 `氣` 용례가 있지만, 이를 起運 target의 정지·배제 규칙으로 정의하는 문장은 보이지 않는다.

따라서 다음은 여전히 닫히지 않는다.

- `節氣`가 이 witness에서 정확히 12節만을 뜻하는지 여부
- 中氣를 포함하거나 제외하는지 여부
- `節`·`氣`·`候`·`令`의 문헌 내부 기술적 분류
- `節止·不論中氣`의 생략·변형·전승 여부
- 특정 판본 계보, 공통 저본, 선후, 독립성, 정본성
- 원작자·편찬자 의도, semantic authority, interpretation/production readiness
- 현대 절기 API, 천문시각, timezone, endpoint, rounding 및 계산 규격
