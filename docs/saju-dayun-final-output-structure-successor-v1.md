# 起運 final output structure: `奇`·`零`·`欠` bounded successor v1

상태: `page-level output structure direct`, `奇/零 remainder role bounded repeated`, `欠 deficit role bounded repeated`, `source-local unit conversion`, `modern age/rounding/readiness blocked`

기준일: `2026-08-26 KST`

이 문서는 [起運 endpoint equality successor](./saju-dayun-endpoint-equality-boundary-successor-v1.md)와 [足·多·欠/借 successor](./saju-dayun-endpoint-foot-surplus-deficit-successor-v1.md)의 additive successor다. 기존 `一歲奇九月`, `四年零九月`, `五歲上運欠三月` 표기를 덮어쓰지 않고, 여러 page surface에서 직접 확인된 최종 출력의 공통 구조와 문헌별 표현 차이를 분리한다.

## 1. Bounded conclusion

직접 원면에서 반복 또는 명시적으로 확인되는 좁은 구조는 다음이다.

```text
raw 日·時 count
  → source-local conversion/output quantity
  → whole 歲 + residual 月 (`奇` or `零` surface)
  → next whole 歲 boundary shortfall (`欠` surface, when reported)
```

현재 안전하게 승격하는 명제는 다음뿐이다.

1. `一歲奇九月`은 《五行精紀》 卷33 계열의 worked example에서 `六百三十日` 뒤에 붙어, 한 정수 歲 뒤의 잔여 九月을 함께 보고하는 출력으로 반복된다.
2. 《子平命術要訣》 p.18의 `五十七月合四年零九月`은 총 月 수를 정수 年과 잔여 月으로 다시 적는 직접 출력이다.
3. 같은 page의 `五歲上運欠三月`은 앞의 `四年零九月`을 다음 정수 歲 표지와 비교해 부족한 三月을 보고하는 source-local 표현이다.
4. 《命理集成》 p.68의 `有餘為零。零即多也。不足當借。借即欠也`는 잔여/부족 표지의 명시적 규칙 문장으로, `零`과 `欠`의 page-local 역할을 보강한다.

이것은 현대의 나이 표기, 모든 문헌의 공통 출력 규격, 반올림·절삭 정책, semantic authority 또는 readiness를 확정하지 않는다.

## 3. Direct worked-example comparisons

### 3.1 `一歲奇九月`: whole year plus residual month

K3-437 p.72, NLC `KOL000000585` target window, 중국 NLC manuscript p.50, 그리고 관련 《命理集成》 page에서 다음 ordered fragment가 직접 확인된다.

```text
十二月二十四日巳時生
是月二十九日申時立春
得五日三時
節氣實歷過六十三時
折除計六百三十日
乃是一歲奇九月之大運
起於丁丑
```

이 sequence에서 직접 닫히는 것은 다음이다.

- `六百三十日`과 `一歲奇九月`이 한 worked example의 연속 출력이다.
- `奇九月`은 `一歲` 뒤의 잔여 月을 보고하는 위치에 있다.
- 같은 문단의 `今人行運多用約法以一歲奇八月`은 별도의 약법 비판값이므로 `奇九月`의 대체 표준값으로 합치지 않는다.

`630日 = 1년 + 9개월`이라는 산술 펼침은 인접 문면의 `三十日/一歲` 관계를 이용한 source-local replay다. 이를 현대 달력의 실제 월 길이 또는 일반 계산 규격으로 승격하지 않는다.

### 3.2 `四年零九月`: total 月 → 年 + residual 月

《子平命術要訣》 p.18의 같은 page에는 다음이 이어진다.

```text
共得十四日零三時。
年公式計：得（10[12×14＋3]÷30＝57）
五十七月合四年零九月。
簡言之則為：五歲上運欠三月。
```

이 page는 앞의 raw 日·時 count를 먼저 `五十七月`로 명시하고, 그 뒤를 `四年零九月`로 분해한다. 따라서 이 surface에서 `零`은 “0개월”이 아니라 정수 年 뒤에 이어지는 잔여 月을 표시하는 연결·출력 표지로 읽힌다. 이는 page-local 산술과 다음 규칙 문장에 근거한 판정이며, 모든 문헌의 `零` 용법을 자동 정규화하지 않는다.

### 3.3 `五歲上運欠三月`: next whole-year boundary shortfall

`五歲上運欠三月`은 독립된 두 번째 interval이 아니라 바로 앞의 `四年零九月`을 `五歲`라는 다음 정수 歲 표지와 함께 설명하는 문장이다.

```text
57月 → 四年零九月
五歲上運欠三月
```

따라서 직접 승격되는 의미는 “이 사례에서 五歲 표지까지 三月이 부족함”이다. `欠`을 음수 나이, 별도의 출생 후 기간, 또는 모든 문헌의 endpoint operator로 일반화하지 않는다.

### 3.4 `零·欠`의 명시적 규칙 문장

NLC-attributed 《命理集成》 p.68은 같은 起運 문맥에서 다음을 직접 보인다.

```text
以三日為一歲。
六日為二歲。九日為三歲。三十日為十歲。
有餘為零。零即多也。不足當借。借即欠也。
```

이 문장은 `零`을 완년수에 더해지는 surplus/remainder 쪽, `借·欠`을 완년수에 미달하는 deficit 쪽으로 구분한다. 그러나 `奇`라는 글자를 이 문장 자체가 정의하지는 않는다. `奇`의 잔여 역할은 《五行精紀》 계열의 직접 worked output과 `六百三十日`의 연속 관찰에서만 bounded하게 보강한다.

### 3.5 year-only compact outputs: 문헌별 차이

NLC `99036` 《淵海子平》 p.51에는 다음과 같은 다른 출력 방식이 있다.

```text
十五日 → 五三十五 → 五歲 → 逆行丁丑
得九日 → 三三單九 → 三歲 → 逆行乙丑
```

이 page는 결과를 `五歲`·`三歲`처럼 정수 歲로 적지만, `五三十五`·`三三單九`의 literal 산술은 이 문서에서 정규화하지 않는다. 따라서 모든 문헌이 `歲+月` 잔여를 끝까지 출력한다고 일반화할 수 없고, `一歲奇九月` 또는 `四年零九月`과 동일한 표기 체계로 환산하지 않는다.

## 5. H/E/L/S/I/P boundary

| layer | state | reason |
|---|---|---|
| H: institutional/catalog identity | `partial/direct` | K3 official record, NLC/KORCIS routes, NCL official record; public derivatives are separately marked |
| E: physical item / exact digital derivation | `partial/unresolved` | K3 page route is direct; supplied/public derivative raw-byte and machine binding remain separate blockers |
| L: edition/textual lineage | `unresolved` | repeated output structure is not a common ancestor or direct dependence proof |
| S: source wording | `direct` | target pages visibly contain the output strings and surrounding arithmetic |
| I: semantic interpretation | `bounded/unresolved` | `奇·零·欠` roles close only in their page-local contexts; lexical identity is not closed |
| P: production/readiness | `blocked` | no modern age, endpoint, rounding, timezone, API, or authority contract is established |

## 6. Non-promotion boundary

이 successor는 다음을 주장하지 않는다.

- `一歲奇九月`을 현대의 “만 나이/세는나이” 출력으로 변환하는 규칙.
- `四年零九月`을 모든 문헌에서 `57개월`로 자동 재계산하는 규격.
- `五歲上運欠三月`을 현대 `<`, `<=`, floor, ceil, nearest 중 하나로 구현하는 규칙.
- `一時→十日`, `一日→四箇月`, 30일 월·360일 년의 현대적 보편화.
- `奇·零·欠`의 특정 문헌 간 직접 계보, 공통 저본, 정본성, semantic authority.
- interpretation readiness 또는 production activation.
