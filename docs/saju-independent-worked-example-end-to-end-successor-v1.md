# 《子平命術要訣》 independent worked example end-to-end 起運 flow bounded successor v1

상태: `frontier advanced: second title-level page-surface worked case`; `copy independence/lineage/semantic authority/readiness blocked`

기준일: `2026-08-26 KST`

이 문서는 [기존 《命理探原》 joined-flow successor v2](./saju-month-pillar-dayun-joined-source-grounded-flow-successor-v2.md)의 additive successor다. 목적은 《命理探原》 사례를 다시 세는 것이 아니라, **별도 제목의 고전 worked example**에서 생년·節 경계·月柱·순·역·起運 나이·첫 大運·후속 大運이 실제 원면 이미지에 한 사례로 연결되는지 확인하는 것이다.

여기서 `independent`는 《命理探原》과 다른 제목/scan surface라는 뜻으로만 사용한다. 공개 derivative의 기관 원본 raw bytes, exact machine binding, physical-copy independence, 판본·전승 lineage는 별도 gate이며 이 문서가 닫지 않는다.

## 1. 결론: 새로 닫힌 최대 범위

NLC-attributed 공개 scan 《子平命術要訣》 PDF p.18(인쇄면 `十四`)의 동일 worked block에서 다음 순서가 직접 관찰된다.

```text
丙申年十月十八日申時生男
  → 十一月初二日亥正一刻八分交大雪節
  → 丙年生男為陽男；順數
  → 十一月初二日亥時；共得十四日零三時
  → 五十七月合四年零九月；五歲上運欠三月
  → 四柱：丙申年、己亥月、己卯日、壬申時
  → 五歲上庚子運
  → 十五歲上辛丑運
  → 二十五壬寅（同面列式의 source age label）
```

이것은 다음을 **source-local direct/bounded relation**으로 전진시킨다.

- 출생 tuple과 source가 적은 target 節이 같은 계산 예문에 있다.
- 출생 tuple 뒤에 source가 `己亥月`을 포함한 四柱를 직접 적는다.
- 같은 문맥에서 `陽男`·`順數`와 `庚子` 첫 大運이 직접 붙는다.
- 같은 page의 문장·列式에 `辛丑`·`壬寅` 후속열이 이어진다.

이 sequence를 현대 함수로 재생산하거나, 공개 scan을 기관 보존본의 canonical byte로 취급하지 않는다.

## 3. p.18의 worked block

### 3.1 규칙 문장과 example의 위치

같은 p.18의 `推大運` 문단에는 다음 source wording이 직접 보인다.

```text
陰男。如甲年生男為陽男。生女為陽女。乙年生男為陰男。生女為陰女。是也。
推大運時。先從所生之日起陽男陰女順行。數至未來節。
陰男陽女逆行。數至已過去節。皆遇節即止。中氣不論。
```

이어서 source는 `觀其日數時數之多少`, `三日為一歲`, `一時為十日`, `有餘為零`, `不足為借` 및 `均從月上起`를 적은 뒤 example과 산식을 제시한다. 이 문장은 해당 page에서 직접 확인한 textual layer로만 보존한다. 특히 `一時為十日`을 현대의 시간 단위로 환산하거나, `中氣不論`을 《五行精紀》·다른 문헌 전체의 보편 규칙으로 전이하지 않는다.

### 3.2 입력·target·순행·raw 결과

worked block의 직접 판독 범위는 다음과 같다.

```text
例如丙申年十月十八日申時生男。
查曆書本年十一月初二日亥正一刻八分交大雪節。
因丙年生男為陽男。
故從十月十八日申時順數至十一月初二日亥時。
共得十四日零三時。
```

이 면에서 닫히는 claim은 다음이다.

| 단계 | 원면 literal | 상태 | 안전한 의미 |
|---|---|---|---|
| 출생 입력 | `丙申年十月十八日申時生男` | `direct, case-local` | worked input tuple 보존 |
| target boundary | `十一月初二日亥正一刻八分交大雪節` | `direct, named target` | source가 적은 target명·정밀 표기 보존 |
| 방향 | `丙年生男為陽男`·`順數` | `direct, case-local` | 이 example의 남성·순행 표지 보존 |
| 계산 endpoint 표기 | `順數至十一月初二日亥時` | `direct, coarse endpoint` | source가 사용한 endpoint token 보존 |
| raw result | `共得十四日零三時` | `direct, source-reported` | source가 보고한 일·시 수량 보존 |

`亥正一刻八分`에서 `亥時`로 넘어가는 관계는 이 example의 fine→coarse 표기 관찰이다. 이를 역사적 절삭·포함/배제 연산, 현대 timezone, endpoint operator 또는 rounding 규격으로 확장하지 않는다.

### 3.3 起運 나이와 月柱의 source-visible association

같은 block은 raw 결과 뒤에 다음 출력들을 계속 적는다.

```text
五十七月合四年零九月。
簡言之則為五歲上運欠三月。
……知此人之四柱為丙申年、己亥月、己卯日、壬申時。
```

직접 승격되는 범위는 다음과 같다.

- `十四日零三時` 뒤에 source가 `五十七月` 및 `四年零九月`을 적는다.
- 이어서 `五歲上運欠三月`을 “간단히 말한” 결과로 적는다.
- source가 그 example의 四柱를 `丙申年·己亥月·己卯日·壬申時`로 명시한다.
- page의 앞 규칙 문장 `均從月上起`와 이 example의 `己亥月`·`庚子` 출력은 **이 사례에 한한 source-visible association**으로 기록한다.

여기서 `己亥月`은 원면에 인쇄된 四柱 field이지, 현대 節 API로 다시 산출한 값이 아니다. 따라서 이 문서가 닫는 것은 “이 source-local example이 그 月 field와 결과를 함께 보고한다”는 사실이며, 모든 생년월일시의 月柱 생성기나 月建→first 大運 공식이 아니다.

### 3.4 첫·후속 大運

같은 p.18의 example 문장과 인접한 `式一`/列式에서 다음 row를 직접 확인한다.

```text
五歲上庚子運。
十五歲上辛丑運。依次順行。

同一 worked block의 四柱 row：丙申／己亥／己卯／壬申
列式의 후속 row：二十五壬寅
```

따라서 다음 결합은 page-level direct다.

| source 출력 | 직접 판정 |
|---|---|
| `五歲` → `庚子` | first 大運이 해당 source age marker와 함께 인쇄됨 |
| `十五歲` → `辛丑` | second row가 같은 순행 example에 인쇄됨 |
| `二十五` → `壬寅` | 같은 page의 列式에서 third row가 이어짐; 반복된 `歲`는 보충하지 않음 |
| `庚子→辛丑→壬寅` | 이 page에 인쇄된 순행 후속열의 literal progression |

`壬寅` row가 식의 배치상 prose와 떨어져 보이더라도, `丙申·己亥·己卯·壬申` 四柱 row와 같은 page의 해당 `式一`/列式 안에서 확인한 것이다. 이를 다른 example의 `戊戌→丁酉→丙申` 역행열과 섞어 하나의 birth case로 만들지 않는다.

## 4. end-to-end source-grounded flow

### 4.1 이 page에서 연결 가능한 chain

```text
[birth]
丙申年十月十八日申時生男
  ↓
[named target]
十一月初二日亥正一刻八分交大雪節
  ↓
[direction]
丙年生男為陽男；順數
  ↓
[source endpoint/count]
至十一月初二日亥時；十四日零三時
  ↓
[source-local output]
五十七月合四年零九月；五歲上運欠三月
  ↓
[printed month field / four pillars]
丙申年、己亥月、己卯日、壬申時
  ↓
[first/next/later dayun]
五歲庚子 → 十五歲辛丑 → 二十五壬寅
```

각 화살표는 source가 같은 p.18에 인쇄한 field·문장·列式을 이어 읽은 bounded relation이다. 다음은 이 chain의 일부가 아니다.

```text
현대 절기 시각을 다시 계산하여 target을 선택하는 단계
현대 timezone/진태양시/API로 raw interval을 재산출하는 단계
`欠三月`을 floor/ceil/nearest 또는 < / <=로 해석하는 단계
`己亥`에서 모든 경우의 first 大運을 자동 생성하는 단계
```

### 4.2 이전 frontier와의 관계

기존 《命理探原》 p.55·p.60–61은 같은 title surface 안에서 `丙午·庚寅` case의 月柱→순행→起運→`辛卯→壬辰→癸巳`를 닫았다. 이번 p.18은 **다른 제목/공개 scan surface**에서 다음 대응을 추가한다.

```text
子平命術要訣：丙申·己亥·己卯·壬申
  → 陽男順數
  → 大雪節 / 十四日零三時
  → 五歲上運欠三月
  → 庚子→辛丑→壬寅
```

따라서 “한 source-local worked case에서 전체 구조를 읽을 수 있다”는 형태가 title-level로 두 surface에 반복된다. 그러나 두 surface의 기관 physical copy가 서로 독립인지, 어느 쪽이 선행하는지, 같은 저본을 공유하는지는 이 관찰로 판단하지 않는다.

## 7. 독립성·계보·authority 판정

현재 판정은 다음처럼 층을 분리한다.

```text
page image observation
  ├─ 子平命術要訣 p.18: one title-level worked case, direct
  └─ 命理探原 p.55·p.60–61: separate title-level worked case, existing direct

bounded repetition
  └─ two title/page surfaces show the same ordered claim shape

not established
  ├─ the two scans are independent physical copies
  ├─ one text directly derives from the other
  ├─ common ancestor, edition order, or textual independence
  ├─ either page is a semantic canonical authority
  └─ either surface is ready for modern calculation/production activation
```

`NLC416-13jh000981-42624` 파일명과 공개 viewer는 surface identity와 page retrieval을 돕지만, 기관 확인이 없는 상태에서 item-level catalog claim이나 raw-byte provenance로 승격하지 않는다.
