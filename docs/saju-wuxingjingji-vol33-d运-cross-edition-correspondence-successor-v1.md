## 3. Directly observed textual correspondence

### 3.1 Introductory and directional passage

The following literal fragments are visible in the overlapping page windows, with only page wrapping and column segmentation differing:

```text
運行則一辰十歳折除乃三日為年
窮通變以為玄
王氏注云夫運者人生之傳舍推命之說
先以三元四柱五行生死格局以定根基
然考寅運運氣懈而從之以定平生之吉凶也
陽男陰女大運以生日後未來節氣日為數順而行之
陰男陽女大運以生日之前過去節氣日為數逆而行之
```

The conversion discussion also preserves the same observed numeric family, including `一辰十歳`, `三日為年`, `一月`, `三十日`, `十二時`, and the `三百六十日`/`一歲` progression. These are recorded as directly observed textual fragments, not as an implementation rule.

### 3.2 `甲子陽男` worked example

The three sources preserve the following ordered example sequence in the inspected window:

```text
譬如甲子陽男
十二月二十四日巳時生
是月二十九日申時立春
陽男數未來之日
自二十四日巳時至二十五日巳時
得五日三時
節氣實歷過六十三時
折除計六百三十日
乃是一歲奇九月之大運
起於丁丑
```

The later 約法 critique is likewise observed in the three page sequences:

```text
方是甲子十二月生行一歲奇九月之大運也
今人行運多用約法以一歲奇八月起運
便以二歲九月過矣殊不明折除實歷之數也
```

The Yonsei screenshots do not provide a machine-readable transcription. The characters above are bounded visual readings shared with the already inspected K3 and NLC images; uncertain small glyphs are not normalized into a variant claim.
