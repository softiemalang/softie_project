# DE405 controlled build matrix

This evidence isolates compiler/build-condition effects on one Apple arm64 host. The source, CSPICE N0067 archives, DE405 kernel, 150,671-row sample corpus, wrapper, JSONL serialization, locale, and execution order are held constant. The four Apple clang variants are:

- `-O0 -ffp-contract=off`
- `-O2 -ffp-contract=off`
- `-O2 -ffp-contract=fast`
- `-O2 -ffp-contract=fast -ffast-math -Wno-nan-infinity-disabled`

The runner is `scripts/run-de405-controlled-build-matrix.mjs`; raw generated output is materialized under `artifacts/de405-controlled-build-matrix/` and can be isolated under `/private/tmp/de405-controlled-build-matrix/`. The analyzer and checker are `scripts/analyze-de405-controlled-build-matrix.mjs` and `scripts/check-de405-controlled-build-matrix.mjs`. The compact persistent triangle provenance is generated by `scripts/materialize-de405-controlled-build-triangle.mjs` into `docs/de405-controlled-build-triangle-evidence.json` and `.md`.

The observed Apple classification is `compiler_effect_not_observed_os_architecture_remains`: all three comparisons are bitwise identical over all 150,671 rows and six state components, so there is no first divergence and the maximum ULP and absolute difference are zero. This does not test compiler-family sensitivity because no alternate compiler family is installed, and it does not separate Apple arm64 from Linux x86_64. The triangle classification is `blocked_linux_arm64_control_unavailable`: this host has no installed Linux arm64 runtime, container engine, VM, or QEMU executable. Existing Linux x86_64 evidence remains separately recorded with its Alpine/musl/QEMU provenance. Production routing, tolerances, contracts, and architecture are unchanged.
