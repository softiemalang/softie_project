# DE405 historical evidence reconciliation

The historical Alpine record used the same 150,671 sample/SPK/canonical hash identity and was reproducible, but it compared a shadow baseline/candidate and canonical-route recomposition stream. It did not preserve an ordered Apple/Linux pairwise canonical-v2 raw state stream, so a cross-platform arithmetic first divergence cannot be claimed from that artifact.

The historical execution was Alpine 3.22.1/musl, x86_64 under QEMU x86_64 on Darwin arm64. GCC 14.2.0 and Clang 20.1.8 were both reported, but the Clang shadow used GCC-built CSPICE archives. The recorded 54,789 Linux candidate mismatches and 62,025 Linux baseline non-exact rows therefore remain mixed OS/libc/compiler/linkage/emulation evidence, not a general platform-sensitivity result.

The current official-source Apple arm64 dual-build, Ubuntu 24.04 x64↔arm64, and Apple↔Ubuntu canonical-v2 evidence has result SHA-256 `07b51b47dee7042056f7b127886e93f7f0d84283348d5a941f8be27ca65ac08b`, 150,671 rows, and zero differing components. The successful native matrix run `30768814210` additionally establishes bitwise identity for Ubuntu glibc/GCC ↔ Alpine musl/GCC, Ubuntu glibc/GCC ↔ Alpine musl/Clang, and Alpine GCC ↔ Alpine Clang, each over 150,671 rows and 904,026 state components, with no first divergence and zero ULP/absolute distributions. The Alpine GCC and Clang variants used the same frozen image filesystem and differed only in compiler selection.

The final bounded conclusion is `canonical_v2_cross_environment_bitwise_identity_established`: for the fixed CSPICE N0067 source, DE405 SPK, canonical-v2 runner, corpus, and explicit floating-point flags, every tested Apple arm64, Ubuntu glibc x64/arm64, Alpine musl GCC, and Alpine musl Clang combination was bitwise identical. This is not a universal platform theorem and does not change production tolerances or activation contracts. It does not retroactively invalidate the historical record; it supersedes only the broader interpretation of that record.

Run `node scripts/reconcile-de405-historical-evidence.mjs` for the fail-closed reconciliation checker. The new manual workflow `.github/workflows/de405-legacy-native-matrix.yml` compares an Ubuntu glibc control with native x64 Alpine GCC and Clang variants. QEMU is forbidden. Raw JSONL stays in Actions artifacts; only the deterministic summary is produced by the collector.

The persisted matrix summary and separate remote execution record are `docs/de405-legacy-native-cross-environment-summary.json`, `.md`, and `docs/de405-legacy-native-cross-environment-remote-record.json`. Raw JSONL and the OCI archive remain outside the repository under the Actions-artifact retention contract. The prior triangle evidence remains a historical controlled-build record with Linux arm64 unavailable; this native x64 matrix is a separate superseding evidence layer and does not rewrite that record.
